#设计

个人在线服务网站Loveconvert上线啦! 服务器在洛杉矶，国内访问速度一般，欢迎大家访问： http://www.loveconvert.com 或者http://loveconvert.com PC端和移动端都可以使用哦~~

#目前主要功能：

  1. Word ( Word转PDF、Word转XPS、Word转JPG、Word转TXT、doc转docx、docx转doc )
  2. Excel ( xls转xlsx、xlsx转xls )
  3. PPT ( ppt转pptx、pptx转ppt )
  4. 在线图片文件格式转换（支持文件格式：jpg、bmp、emf、gif、ico、png、tif、wmf）

#功能计划：

  1. 在线音频文件格式转换
  2. 在线视频文件格式转换
  3. 在线音视频互转换
  4. 在线汇率转换 在线翻译 在线进制转换 在线加密 等等

请大家持续关注呀! 有需要的功能可以私聊我，目前还存在一些bug，修复中…… 感谢大家支持
