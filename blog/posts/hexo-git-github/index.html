hexo 利用Git发布到Github

🌐 Web 前端 Git 与协作 131 字 约 1 分钟
#Git#Hexo
  1. 在hexo根目录下执行命令，安装hexo-deployer-git（一般默认都有，可以打开根目录下的package.json查看）：
npm install hexo-deployer-git --save
  1. 找到github项目对应的git地址：

  1. 在根目录下的_config.yml文件末尾添加配置：
deploy:
  type: git
  repository: https://github.com/garuhester/garuhester.github.io.git
  branch: master
  1. 在hexo根目录依次执行命令：
$ hexo clean //清除缓存
$ hexo g //生成静态网页文件
$ hexo d //发布到github

为了方便使用，可以做成bat文件： 开启服务：hexo clean & hexo g & hexo s Git上传：hexo clean & hexo g & hexo d
