时隔一年的Sublime-Text-3终于更新啦

🎁 资源分享 1014 字 约 3 分钟
#Linux#UI 界面

作为自己最爱的一款编辑器，自从2016年9月23日开始，Sublime Text 3 的版本就一直是3126版本（很多bug）

虽然官方不停的在刷预览版，但是正式的版本一直没有更新，还以为它放弃维护了呢 但是在昨天（2017年9月13日） Sublime Text 3时隔了一年终于迎来了正式版的更新

在Sublime Text 3 Build 3143版本中 更新的东西还是挺多的 首先就是Sublime Text 3 的Logo 发生了改变，下图是新的Logo

然后呢，编辑器内部的一些UI风格也发生了改变

还有就是编辑器的主题有了一点变化

还有很多的变更等着你去发现 总之Sublime Text 3是一款十分强大且好看好用的编辑器 之前还有介绍过Sublime Text 3的一些强大的功能 而且这次更新修复了很多的bug 小伙伴们可以用用，不会让你失望滴 Sublime Text 3 官网：https://www.sublimetext.com/
