一、技术框架

vue + element

二、项目下载与使用

node 下载地址：https://nodejs.org/zh-cn/ git 下载地址：https://git-scm.com/downloads

1. 克隆项目

git clone https://git.wewin.com.cn:9500/fondation-group/front-base-framework/vue-element-template.git

没有权限请找胡力中添加

2. 安装依赖

npm install

1.如果安装失败，可手动添加源： npm install --registry=https://registry.npm.taobao.org 2.如果存在 node-sass 安装失败，请设置 node-sass 镜像地址： npm config set sass_binary_site http://npm.taobao.org/mirrors/node-sass/

3. 运行

npm run server

(默认用户名：superadmin 默认密码：123456)

4. 打包

npm run build

四、IP 配置与请求配置

1. 分环境配置 IP

IP 配置统一在根目录/public/config.js中配置，会自动切换开发环境和正式环境，也可以自行添加其他相关 IP 地址，在 VUE 页面使用this.$publicConfig.ip来访问

2. 接口 IP 选择

项目中可配合 PIM 项目使用 mock 虚拟数据进行前端提前开发。mockIP 的配置在 utils/request.js 文件中，通过控制 Api 文件下的各个 js 文件的 true 与 false 来选择使用服务器 IP 或者 mockIP，如下图

request.js 文件是前端 axios 请求的封装文件，包含了请求时接口增加验签功能（通过 MD5 加密）和接收时的请求拦截，开发时可自行修改。

六、公共样式

路径：assets/styles

1. index.scss

用于放置全局的 css 类

2. variables.scss

配置主题色即可，其他根据注释自行调整

3. element-variables.scss

elementui 主题色配置，默认 primary 用的是 variables.scss 中的主题色

4. table.scss

标准表格模板样式封装，有需要请自行调整

七、工具类 utils 文件

1. index.js

主要工具文件，该文件封装了时间格式化功能，随机 uuid，base6 加密等公共功能函数，可根据项目需要自行添加。

2. auth.js

token 设置，一般只修改 TokenKey 名称

3. getPageTile.js

获取项目的标题并显示在页面标题上，可更具需要删除，并删除相应的调用，如图

4. permission.js

权限控制文件，一般不做修改

5. request.js

axios 封装函数，对请求增加拦截添加 token，和验签，对返回增加 code 判断，可根据项目自行修改

2. 表格高度自适应

为el-table添加v-adaptive指令，bottomOffset参数代表距离底部的距离，默认为 75，请自行调整

3. 表格单元格复制

为el-table-column中template下的span添加v-copy指令，text参数代表需要点击复制的内容（只有当内容过多出现省略号的时候才能点击进行复制）

4. 基础表格页模板

如需对基础表格页模板进行调整，组件路径为：components/table/...

具体请参考views/template/template-table.vue结构

表格页结构：

组件详情：

  • table-query(表格条件筛选) 内部直接放需要查询的字段

  • table-box(表格容器) 内部放功能按钮以及表格

属性说明:

属性名 说明 默认值
pagination、handleSizeChange、handleCurrentChange 均为默认，无需修改 -
isPaginationShow 显示分页 true

slot 说明：

名称 说明
btn 新增、导入等功能按钮
content 自定义列组件和表格

  • table-select(自定义列) 属性说明:
属性名 说明 默认值
selectedNum、table-line、refresh、clear 均为默认，无需修改 -
isSelectShow 显示已选择和清空按钮 true

  • add-or-update(新增、修改弹窗) 请参考views/template/template-table-add-or-update.vue结构

5. 基础行内编辑表格页模板

请参考views/template/template-line-table.vue结构

7. 图标选择

<el-popover placement="bottom-start" width="650" trigger="click" @show="$refs['iconSelect'].reset()">
    <IconSelect ref="iconSelect" @selected="selected" />
    <el-input class="menu-icon" slot="reference" v-model="iconName" placeholder="点击选择图标（可输入element图标）">
        <svg-icon v-if="iconName" slot="prefix" :icon-class="iconName" class="el-input__icon" style="height: 32px; width: 16px" />
        <i v-else slot="prefix" class="el-icon-search el-input__icon" />
    </el-input>
</el-popover>

data() {
    return {
        iconName: "",
    };
},

methods: {
    selected(name) {
        this.iconName = name;
    },
}
