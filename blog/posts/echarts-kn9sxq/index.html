Echarts实现内部横向滚动条

🌐 Web 前端 图表与可视化 58 字 约 1 分钟
#ECharts

如果x轴数据过多，那么图标下方将显示不全，像这样：

Echarts实现内部横向滚动条，在配置项里加上：

dataZoom: [
    {
        show: true,
        realtime: true,
        start: 0,
        end: 50
    },
    {
        type: 'inside',
        realtime: true,
        start: 0,
        end: 50
    }
]
