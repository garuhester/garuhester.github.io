node 摄像头多路推流

一、项目属性

  • 项目简介：node 摄像头多路推流

  • 项目类别：基础框架

  • 项目地区：无

二、开发环境

1. 环境配置

  • Node 版本：V14.17.x
  • NPM 版本：6.14.x

2. 运行方式及命令

  • 步骤一

安装依赖 npm install

  • 步骤二

把目录里面的 ffmpeg.exe 添加到系统的环境变量中

  • 步骤三

运行根目录中的 node-start.bat 文件启动服务

  • 步骤四

打开根目录下 test/index.html 即可看效果

wifi请连接WEWIN，才能访问示例中的摄像头地址

3. 注意事项

  • 项目路径请不要有中文

  • 根目录中.bat文件说明： forever-list.bat：查看运行的服务列表 forever-start.bat：静默启动当前服务 forever-stop.bat：关闭当前服务 forever-restart.bat：重启当前服务

三、部署手册

  • 步骤一

全局安装forever npm install -g forever

  • 步骤二

测试：启动根目录中的 forever-start.bat 文件，查看页面是否显示监控画面

  • 步骤三

将根目录中的 forever-start.bat 文件创建快捷键方式，放入开机启动项目录（可按win+R，然后执行命令shell:Common Startup打开目录）

四、更新日志
