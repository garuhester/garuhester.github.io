如何新增文章

  1. 把新的 .md 文件放进对应的分类目录（如 WEB/、Godot/），或者新建一个目录作为新分类。
  2. 在项目根目录执行 cd tools && npm run build，站点会重新生成到 blog/。
  3. 想自定义标题、标签或摘要，可在文件开头加 front matter：title / date / tags / summary / draft。

快捷键

  • / 或 ⌘K / Ctrl K：打开搜索
  • Esc：关闭搜索
  • 文章内点击图片可放大查看，代码块右上角可一键复制
