##1.在简书个人文章页面按F12，打开控制台(先往下翻，把文章都显示出来，因为简书文章是动态加载)
![](https://upload-images.jianshu.io/upload_images/2381669-a588e878cef418ad.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

##2.复制下方代码，在控制台粘贴代码，回车运行
```
var num=0;for(var i=0;i<document.querySelectorAll(".note-list .meta").length;i++){num += parseInt(document.querySelectorAll(".note-list .meta")[i].querySelectorAll("a")[0].innerText)};console.log("文章总阅读量：" + num + "次")
```

##3.即可
