# 前端：后台管理系统基础框架

## 一、技术框架

vue + element

## 二、项目下载与使用

> node 下载地址：[https://nodejs.org/zh-cn/](https://nodejs.org/zh-cn/)
> git 下载地址：[https://git-scm.com/downloads](https://git-scm.com/downloads)

### 1. 克隆项目

```
git clone https://git.wewin.com.cn:9500/fondation-group/front-base-framework/vue-element-template.git
```

没有权限请找胡力中添加

### 2. 安装依赖

```
npm install
```

> 1.如果安装失败，可手动添加源：
> npm install --registry=https://registry.npm.taobao.org 2.如果存在 node-sass 安装失败，请设置 node-sass 镜像地址：
> npm config set sass_binary_site http://npm.taobao.org/mirrors/node-sass/

### 3. 运行

```
npm run server
```

> (默认用户名：superadmin 默认密码：123456)

### 4. 打包

```
npm run build
```

## 四、IP 配置与请求配置

### 1. 分环境配置 IP

IP 配置统一在`根目录/public/config.js`中配置，会自动切换开发环境和正式环境，也可以自行添加其他相关 IP 地址，在 VUE 页面使用`this.$publicConfig.ip`来访问

![](https://upload-images.jianshu.io/upload_images/2381669-19494105fb931bdf.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

### 2. 接口 IP 选择

项目中可配合 PIM 项目使用 mock 虚拟数据进行前端提前开发。mockIP 的配置在 utils/request.js 文件中，通过控制 Api 文件下的各个 js 文件的 true 与 false 来选择使用服务器 IP 或者 mockIP，如下图

![](https://upload-images.jianshu.io/upload_images/2381669-5dee66e0463292e0.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

![](https://upload-images.jianshu.io/upload_images/2381669-51cd06b1741b385e.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

request.js 文件是前端 axios 请求的封装文件，包含了请求时接口增加验签功能（通过 MD5 加密）和接收时的请求拦截，开发时可自行修改。

## 七、工具类 utils 文件

### 1. index.js

主要工具文件，该文件封装了时间格式化功能，随机 uuid，base6 加密等公共功能函数，可根据项目需要自行添加。

### 2. auth.js

token 设置，一般只修改 TokenKey 名称

### 3. getPageTile.js

获取项目的标题并显示在页面标题上，可更具需要删除，并删除相应的调用，如图

![](https://upload-images.jianshu.io/upload_images/2381669-95e3d3215a43c0e5.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

### 4. permission.js

权限控制文件，一般不做修改

### 5. request.js

axios 封装函数，对请求增加拦截添加 token，和验签，对返回增加 code 判断，可根据项目自行修改

### 7. 图标选择

```
<el-popover placement="bottom-start" width="650" trigger="click" @show="$refs['iconSelect'].reset()">
    <IconSelect ref="iconSelect" @selected="selected" />
    <el-input class="menu-icon" slot="reference" v-model="iconName" placeholder="点击选择图标（可输入element图标）">
        <svg-icon v-if="iconName" slot="prefix" :icon-class="iconName" class="el-input__icon" style="height: 32px; width: 16px" />
        <i v-else slot="prefix" class="el-icon-search el-input__icon" />
    </el-input>
</el-popover>

data() {
    return {
        iconName: "",
    };
},

methods: {
    selected(name) {
        this.iconName = name;
    },
}
```
