# 属性：

父元素属性：
- grid-template-columns
- grid-template-rows
- grid-template：rows / columns
---
子（列）元素属性：
- grid-column-start
- grid-column-end
- grid-column：start / end
---
子（行）元素属性：
- grid-row-start
- grid-row-end
- grid-row：start / end
---
子（区域：列和行）元素属性：
- grid-area：row-start / column-start / row-end / column-end
