# 插件模板 makeid-template

## 一、插件属性
- 插件id：makeid-template
- 插件分类：单元插件 (unit)
- 插件版本：v1.0.0

## 二、插件依赖
- 基础框架核心工具 makeid-core-util

## 三、插件使用

### 5. 配置 config
- 工具：Vue.prototype.makeidLoginTool

|  函数   | 说明  | 参数  | 调用 |
|  ----  | ----  | ---- | ---- |
| changeLoginTemplate  | 切换模板 | loginTemplateType: 模板序号 | `Vue.prototype.makeidLoginTool.changeLoginTemplate(1)` |

- 回调注入：

|  函数   | 说明  | 参数  | 调用 |
|  ----  | ----  | ---- | ---- |
| Vue.prototype.makeidSystemUserLogoutCallback  | 用户退出登录回调注入 | callback: 回调函数 | `Vue.prototype.makeidSystemUserLogoutCallback.push(()=>{})` |
| Vue.prototype.makeidCoreUtilRequest401Callback  | 请求401回调 | callback: 回调函数 | `Vue.prototype.makeidCoreUtilRequest401Callback.push(()=>{})` |
| Vue.prototype.makeidCoreUtilRouteCallback  | 非登录页路由回调 | callback: 回调函数 | `Vue.prototype.makeidCoreUtilRouteCallback.push(()=>{})` |
